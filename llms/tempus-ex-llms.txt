# Tempus Ex — FusionFeed

> Tempus Ex (part of Infinite Athlete) operates FusionFeed, an advanced sports
> data and media API that aggregates schedules, rosters, official and
> AI-automated statistics, low-latency X/Y telemetry, scoreboard data, and
> live/VOD video (HLS + sub-second SRT, plus computer-vision products) for
> gridiron football (NFL, NCAA) and association football (soccer). FusionFeed is
> GraphQL-first with an interchangeable REST interface and WebSocket
> subscriptions, versioned under /v2/.

## API
- FusionFeed base URL: https://feed.fusion.tempus-ex.com/v2/
- GraphQL over HTTP: https://feed.fusion.tempus-ex.com/v2/graphql
- GraphQL subscriptions (WebSocket, graphql-ws): https://feed.fusion.tempus-ex.com/v2/graphql-ws
- REST example: GET /v2/nfl/games?last=100

## Authentication
- API key: `Authorization: token MY_API_KEY_TOKEN`
- JWT (OAuth2 resource server): `Authorization: Bearer MY_JWT_TOKEN` — tokens minted by an external IdP (Okta authorization-code + PKCE, Amazon Cognito, or custom IdP).
- WebSocket: pass `{"authorization": "token MY_API_KEY"}` in graphql-ws connection-init.

## Conventions
- Versioning: URI-path major version (V2); no breaking changes within a major version; deprecated APIs keep working.
- Pagination: Relay cursor connections (edges/node, first/last).
- Rate limits: HTTP 429 (or GraphQL error); `txm-limit-consumption` response header; exponential backoff.
- Timestamps: RFC 3339 wall-clock; HLS `#EXT-X-PROGRAM-DATE-TIME`.
